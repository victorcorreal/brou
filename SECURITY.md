# Reporting security problems in Brou

Report suspected vulnerabilities privately to **team@greatheightssystems.com**, with "Brou security" in the subject. Include the affected version, relevant code and a minimal reproduction using test accounts and synthetic data. Do not send passwords, cookies, private keys or personal browsing history.

Do not disclose an exploitable issue in a public issue or pull request before coordinating with the maintainer. Brou's maintainer is Victor Correal. Reports about this variant should not be sent to Office Commun unless the issue is confirmed to affect upstream and disclosure has been coordinated.

Brou currently uses manual development builds. There is no public automatic-update channel or guaranteed response time. Security fixes need a newly signed build and an explicit installation. See README.md for the retained data identities and signing requirements.
