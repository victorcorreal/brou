# Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** for this repository when available. Alternatively email **team@greatheightssystems.com**, subject **Brou security**. Victor Correal maintains this variant. Please do not open a public issue containing exploit details before coordinating disclosure.

Include the affected commit/version, impact, platform and a minimal reproduction with synthetic data. Do not include real passwords, cookies, private keys, Apple account identifiers, personal browsing history or profiles. We do not need access to your account to reproduce a bug.

The current 1.1.0 source preview is the maintained version; older variants are not a supported release channel. There is no guaranteed response SLA or bug bounty. Security fixes require an updated source/build; the automatic updater is disabled. Public signed distribution remains separate work.

Keep original attribution when a problem also affects Search. Coordinate any upstream disclosure; do not redirect unverified Brou reports to Office Commun.
